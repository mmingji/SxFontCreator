一、打印模板

彩色喷墨优先（黑白喷墨实测也能用）、打印质量选「高」、实际大小（100%）、不勾无边距；先打最后一页自检页量 1cm 方框。

第 1 步「选模板」里先决定写哪些字：单页试打（先验证版式与打印设置；印的是一页名句集锦，汉字一个不重复）/ 常用 6500 字（约 50 页）/ 自定义选字（按分类或检索挑，打全量 8274 字用「全选全部」，约 61 页）。字表 = 《通用规范汉字表》（8105 字）+ 基础字符 169（半角 ASCII、中文标点、常用全角符号），来源点「写哪些字」旁的问号可看。

点「下载模板」得到带日期的 zip，解压后四件：模板 PDF、空白更正册、《使用说明》与字序文件（字序.sxorder）—— 打印前两件，后两件是给程序用的。

字序.sxorder 是干什么的：它记着"这一包纸按什么顺序排字"，第 2 步识别时优先读它定字序。只给程序读 —— 别改名、别编辑、别删（双击打不开是正常的）；真丢了也能靠纸面参考字把字序定出来。

  • 彩色喷墨，打印时选「实际大小 / 100%」（别选「适合页面」）、打印质量选「高」，不要勾「无边距 / 无边框」。
  • 黑白喷墨实测也能用；黑白激光不承诺（它把灰格线打成实心黑点，会混进字形）。
  • 先打文末那页自检页，用尺子量 1cm 方框与 10cm 标尺，确认是 100% 再打全部。
  • 每页 8 行 × 17 格 = 136 格、书写格 1cm；四角定位块、底部的条码、右侧那排小方块都别裁掉。

底部条码 = 这一页的字序（识别时直接读它，最准）；右侧小方块 = 页号 / 档位 / 本页校验码，最底端的数字是给人看的页码。两处都别裁、别涂改、别污损、别折叠 —— 实在读不出来时程序会退回去认参考字，照样能识，只是没那么稳。

第 1 步两块预览：左边是模板第 1 页的真实渲染（与实际打印逐格一致），右边是书写示意 —— 同样版式、每个书写格里已经用工整手写体写好示范；两块都可翻页。

书写示意只看不打印（不带定位块、底部条码与右侧竖带，机器认不了它）；改过选字清单也不必重打旧纸 —— 识别是从纸面上认参考字，旧纸与新纸可以混着传。

二、书写

0.5mm 黑色中性笔，居中书写、别出格：笔画多的字写到刚刚触到格子边，笔画少的字（如日、一、小）居中写小些。

  • 0.5mm 黑色中性笔，一笔写成，不描不改。
  • 居中书写、别写出格子：笔画多的字写到刚刚触到格子边，笔画少的字（如「日」「一」「小」）居中写小些。
  • 同一个字号下你的字比系统楷体略小是正常的（按书写格 1:1 映射、不缩放）；想更大就写到笔画刚触格线 —— 第 3 步「字形体检」摘要会给这一批的占格率中位。
  • 写错的字：用红笔把这一格的参考字圈起来（圈在参考字上、别圈虚线书写格 —— 那个字万一不更正、要保留主区原字形，红圈盖住笔迹会影响成字效果），再到空白更正册上按顺序重写；纸面别翘边、折叠、受潮。

更正册按「主区页码」的顺序写：先写页码最小的那一页上圈出来的字，同一页里按格子从左到右、从上到下。程序是拿"第 1 个被圈的字 ↔ 更正册第 1 格、第 2 个 ↔ 第 2 格"一对一配的，顺序一乱整册更正就全错位。

怕看错圈的顺序，可以在圈旁标个小序号（1、2、3…），真机上这是最省心的做法 —— 两条讲究：① 写在参考字两侧的空白里，别写进虚线书写格（写进格子的字会被当成这个字的笔迹）；② 序号别和红圈连成一笔，连成一片会让"圈"的判定变模糊（程序可能标成"归属待确认"，要你回第 2 步核对一下）。用红笔写的话，彩色扫描时它会和红圈一起被剔除，不会进字形 —— 就算它盖住了参考字、让程序少认出几格，页脚校验码还能把认错的格纠正回来（不用重扫）。

模板每页顶部印着一行要点、右侧中间印着这一页的页码（更正册上也印，两边页码各自从 1 起）。

三、扫描

平板扫描仪、彩色 300dpi、照片模式；纸放正压平，一页一个文件。

  • 平板扫描仪、彩色 300dpi 就够；色彩模式选「照片 / 彩色照片」，不要选「文档 / 文字文档」（它会把红圈的颜色一起改掉）。
  • 关掉扫描软件里的锐化 / 自动曝光 / 去网纹；纸底要去得干净（纸面偏灰会让页脚读不出、甚至整格被当成墨迹）。
  • 一页一个文件、文件名随意；整页方向不对也没关系，程序会自动试 0 / 90 / 180 / 270 度并转正。

手机拍也行：正上方拍、纸占画面 70% 以上、把纸压平；要认红圈就用扫描 App（如扫描全能王）的「智能高清」（默认档） —— 相机直拍与「文档矫正」会把红圈颜色抹淡（实测 9 个圈只认出 0~1 个）。不圈字的件用相机直拍没问题。

四、上传与更正

给一个文件夹（扫描件 + 第 1 步包里的 字序.sxorder），程序自己定出每页写了哪些字；更正配对在同一页的「更正核对」里可以逐行调整（不改就用程序给的那一套）。

  • 建议 Chrome 或 Edge 86 及以上（Win7 上可装到 109）：选文件夹用的是系统对话框，Firefox / Safari 会自动改成普通文件夹选择器，功能一样。
  • 把扫描件与 字序.sxorder 放在同一层文件夹，选中该文件夹即可；选完点「看文件清单」能看清挑了哪些、不要的图片可当场去掉（只动这一轮，磁盘上的文件不动）。字序优先按字序文件定，没有它时靠认纸面参考字。
  • 识别串行进行、可随时中止（已识别的页保留）；一页一张卡片（状态 + 一行统计 + 「看格子」「作废」「重传」），鼠标停在卡片上能看完整信息。
  • 每页会自己校验：纸面右侧竖带里存着"这一页那些字"的指纹，底部条码里直接写着这一页的字序 —— 程序先用字序文件（没有就先用条码）定出字序，再拿纸面上认出来的字重算一遍指纹核对；对不上会先反推页号，仍不中就整页失败并说明原因（重扫那一页、点「重传」即可）—— 不需要逐格核对字。
  • 后来补扫了几页：用「补传扫描件」一次选进来，程序按页号归位（已有这一页就覆盖、新页就追加），补完回第 3 步重新生成一次字体。

写错的字怎么办：更正册按"主区页码先后 + 同一页里格子从左到右、从上到下"的顺序，从第 1 格起、一格一个字。写坏的格用红笔圈掉、在后面按顺序补写；留空的格表示保留主区的原字形（写坏一格不必整册重写）。更正册只保留一份，重传会覆盖旧的。

识别完成后，页面下半部分的「更正核对」并排列出「第 k 个被圈字 ↔ 更正册第 m 格」，可改派 / 删除 / 补录；配对默认生效（不必点确认），看一眼是防"整体错位"的最后一道闸；想退回程序给的配对，点右侧「恢复默认」。

五、生成字体与安装

第 3 步一页到底：填名称表、生成字体、下载 zip；装完记得重启 Word / PS。

  • 第 3 步一页到底：填名称表（族名 / 版本 / 设计者 / 许可等，都有默认值）→ 点「生成字体」→ 同页出现下载区（zip 内是 .ttf / .woff / .woff2 + font.css + 使用说明.txt + preview.html，也能单独取一件）。
  • 不装机也能先看：同页「字体预览」把刚生成的字体注册进页面，实时输入预览、三档字号（24 / 36 / 56 像素）；没收录的字用浅红底标出。标题行右边还有「查看字形总览」「查看网页预览」。
  • 安装：Windows 右键 .ttf → 「为所有用户安装」（或复制到 C:\Windows\Fonts）；macOS 双击 → 「安装字体」。装完请重启 Word / PS（它们只在启动时读一次字体列表）。Word 里到字体列表选这个族名；网页把 font.css 与字体放同目录、用 font-family 引用。
  • Photoshop 有个坑（2026-10-16 实测）：新建文字图层时 PS 会预置占位文本（Lorem Ipsum，"用占位文本填充新文字图层"默认开启），本字体里没有这些字符 → PS 的「字形保护」会立刻把整个文字图层换成系统字体，看着就像"选了字体没生效"。关掉「编辑 → 首选项 → 文字 → 用占位文本填充新文字图层」即可（推荐），或先打字、再全选文字换一次字体。生成字体会自动补一个空格字形（空轮廓、半个汉字宽），打空格不会触发它。
  • 没写的字不会进字体：Word、Photoshop 与浏览器都会回退成系统字体（预览里会被标出来）。已写的字不受影响，也不必一次写完 —— 先写最常用的那批（一级字 + 基础字符约 27 页）就能用起来，之后补写新字、重新生成一次，字形会合并进同一套字库。
  • 写得不理想的字（字形体检）：面板默认收起，点开是四栏（建议重写 / 只是留意 / 重写清单 / 已剔除的字）—— 它只提示、不改字形；可「加入重写清单」（这次不进、以后补）或「剔除」（这个字不要了）。清单里有「下载重写模板」：按这些字印一张模板，写完用第 2 步「补传扫描件」丢回来，写过的字会自动移出清单；重写页写坏了就重新下载一份、重写、再补传（同页号覆盖、后写优先，不需要另配更正册）。
  • 想重来：第 2 步「清空结果」清掉识别结果与字形（模板与名称表保留）；第 3 步「清空全部数据」彻底复位（要求输入「清空」二字确认）。两个动作都不可撤销。

数据只保存在本机浏览器里：刷新、关掉浏览器都不会丢，但清理浏览器数据、换电脑或换浏览器就没有了（那时把扫描件文件夹重指一次、重跑识别即可，全量约 100 秒）。扫描件原图程序不保存，请自己留一份。

六、常见问题

打印尺寸不对、找不到定位块、字写小了、字体装完 Word 里没有 —— 先看这几条。

  • 格子不是 1cm：检查是否选了「实际大小 / 100%」、是否误勾「无边距」；先用自检页量一次。
  • 提示找不到四角定位块：确认纸角完整没被裁、纸面平整、打印是实际大小；重扫一次通常就好。
  • 字写小了、成字偏小：见「二、书写」—— 笔画多的字写到刚刚触到格子边。
  • 字体装上后 Word 里找不到：先重启 Word / PS；仍没有就看包里的使用说明.txt 核对字体字段，或重装一次。
  • PS 里选了字体却没变化：见「五、生成字体与安装」那条 —— 多半是 PS 的「字形保护」被占位文本触发了。
  • 刷新页面后：识别结果与字形都已落盘，重新生成字体不必重扫；格子大图与更正核对的缩略图会当场从落盘字形重画。
  • 能不能只做一部分字：可以。第 1 步「自定义选字」按分类或检索挑字，字网格可按「使用频率 / 笔画序」排序、支持「全选本页」，分类树下方还有「全选全部」；出一批写一批即可。

七、参考与借鉴

版式与流程思路参考了做字体网（zuoziti.com）的公开模板与教程；代码、字体、字表与全部实现均为自研。

本软件的版式几何（A4 横向、17 格 × 8 行、1cm 书写格、灰色格线与灰色参考字）与流程思路（照着写不描红、错字用红笔圈出后单独重写、字形体检与字形总览、名称表中英双语）参考了 做字体网（zuoziti.com） 公开的模板与教程；其中若干口径在实测中被我们修正（字表改用《通用规范汉字表》官方口径、打印从"必须彩色喷墨"放宽为黑白喷墨也可用等）。

除上述版式与思路之外，本软件的代码、字体、字表与全部实现均为自研；做字体网的资料只作为参考文献留在开发仓库之外，不随本软件分发。第三方许可：内置字体霞鹜文楷（模板参考字）与悠哉字体 Yozai（书写示意的示范字）都是 OFL-1.1，许可全文随程序包附在 fonts/ 目录下；生成字体用到的开源库（pdf-lib、pdf.js、fonteditor-core、jszip、esm-potrace-wasm 等）清单见开发仓库的 THIRD-PARTY-NOTICES.md。
