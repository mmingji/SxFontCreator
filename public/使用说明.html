一、打印模板

彩色喷墨优先（黑白喷墨实测也能用）、实际大小（100%）、不勾无边距；先打最后一页自检页量 1cm 方框。

在第 1 步「选字与出模板」里先决定写哪些字：单页试打（先确认版式与打印设置；印的是一篇短文—— 现选《岳阳楼记》名句段，68 字一页放得下，后面留空即可，按短文本身的顺序写）/ 常用 6500 字（一级 3500 + 二级 3000 + 基础字符 169 = 6669 字，约 50 页）/ 自定义选字（按分类或检索挑字；想要全量就打「全选全部」＝ 8274 字、约 61 页）。选好再点「生成并下载模板压缩包」—— 它打出一个带日期的 zip，里面是模板 PDF、空白更正册、《使用说明》与这一批的字序文件（`字序.json`）四件东西：打印的是前两件，后两件留给程序与你自己看。

字表按《通用规范汉字表》（国务院 2013 年公布，8105 字 = 一级 3500 + 二级 3000 + 三级 1605，字序为官方笔画序）收字，另加基础字符 169 个（半角 ASCII 95 + 中文标点 30 + 常用全角符号 44）—— 来源核对与官方说明节选，点第 1 步「写哪些字」旁边的问号就能看到。

  • 用彩色喷墨打印机；打印对话框里选「实际大小 / 100%」，不要选「适合页面」——那会把格子缩放掉。
  • 不要勾「无边距」（有些驱动叫「无边框」）：它会把内容放大到铺满整张纸，格子就不是 1cm 了。
  • 黑白喷墨（用彩色喷墨机的黑白 / 灰度模式）实测也能用：格线在纸面上看着是虚点线，但灰度仍远浅于笔迹，识别不受影响（2026-10-11 实测空白模板件：136 格全判空白，格内最暗像素 188 > 提取阈值 150）。黑白激光不行 —— 它把灰格线打成实心黑点，会混进字形里。
  • 模板文末有一页打印自检页，先打它、用尺子量上面的 1cm 方框与 10cm 标尺，确认是 100% 再打全部。
  • 每页 8 行 × 17 格 = 136 格，书写格是 1cm × 1cm 的实尺寸；页脚那排小方块是页码标记，别裁掉（认不出字序时程序靠它兜底）。

为什么包里要带字序文件：它把"这一批纸按什么顺序排字"写死，识别时程序直接读它 —— 万一文件夹里没有它，程序还能靠认每页印着的参考字把字序定出来（这条路实测也走得通）。

第 1 步的两块预览怎么看：左边是模板第 1 页的真实渲染（用 pdf.js 画出来的，与实际打印逐格一致，最后一页是打印自检页）；右边是书写示意 —— 版式与模板一样，只是每个书写格里已经用工整手写体（悠哉字体）写好了那一格的字，示范"笔画多的字撑满格、笔画少的字居中写小"。两块都跟着当前范围同页数、可以翻页（改了范围、排列方式或选字会自动重出）。

书写示意只看不打印：它不在正式模板 PDF 里，也不带四角定位块与页脚编码 —— 它是给人看的示范，不是能给机器认的模板。

换过选字清单不必重打旧纸：上传时程序是从纸上认参考字、自己定出这一页写了哪些字 —— 改过选字清单、或者隔了几天才补传，都不会让已经写好的纸作废，旧纸与新纸可以混着传。

二、书写

0.5mm 黑色中性笔，居中书写、别出格：笔画多的字写到刚刚触到格子边，笔画少的字（如日、一、小）居中写小些。

  • 用 0.5mm 黑色中性笔；一笔写成，不描不改。
  • 居中书写、大小匀称、别写出格子。
  • 笔画多的字：写到刚刚触到格子边为宜（撑满格、但不要出格）—— 这样整套字的大小才均一。
  • 笔画少的字（如「日」「一」「小」）：本身就该写小一些，居中写即可；硬撑满格反而难看，成字后大小不匀。
  • 同一个字号下，你的手写字看起来会比系统楷体略小一点，这是正常的：成字的大小完全等于你写多大（程序按书写格 1:1 映射，不缩放）。参考实测值：写得满的字字面高度约 0.82em，而系统楷体约 0.86em、宋体约 0.91em —— 想让它更大，就写到笔画刚触到格子边（别出格）。第 3 步的「字形体检」摘要里会给出这一批的占格率中位，一眼就能看出是写小了还是别的问题。
  • 写错的字：用红笔把这一格的参考字圈起来（统一圈参考字，不要圈书写格）；再到压缩包里的空白更正册上重写 —— 顺序见下面那条加粗说明。
  • 纸面别翘边、折叠或受潮：纸张一旦变形（非平面形变），任何透视校正都救不回来。

模板每页顶部印了一行要点，写的时候照着看即可：「A4彩打,不缩放,不勾无边距;0.5mm黑色中性笔,居中书写,别出格,不描不改,写错用红笔圈参考字,防止纸张翘边,折叠,受潮;扫描用照片模式,图像类型彩色,300dpi。」每页右侧中间印着这一页的页码（更正册上也印，两边的页码各自从 1 起、相互独立）。

更正册要按「主区页码」的顺序写：先写页码最小的那一页上圈出来的字、同一页里按格子从左到右、从上到下的先后；一页的圈字写完了，再写下一页的。为什么必须按这个顺序：程序是拿「第 1 个被圈的字 ↔ 更正册第 1 格、第 2 个 ↔ 第 2 格……」这样一对一配的，顺序一乱，整册更正就全错位（写对的字被配到别的字上）。所以写之前先按页码把圈出来的字排一排，再动笔。

三、扫描

平板扫描仪、彩色 300dpi、照片模式；纸放正压平，一页一个文件。

  • 建议用平板扫描仪（实测设备 EPSON L4266 一体机，彩色 300dpi 就够，只用到它约四分之一的能力）。
  • 色彩模式选「照片 / 彩色照片」，不要选「文档 / 文字文档」：文档模式会把红圈的颜色一起改掉，红圈就认不出来了。
  • 纸底也要去得干净：纸面偏灰的件（格线糊成一片灰底）会让页脚读不出、甚至整格被当成墨迹 —— 去底色与保留颜色这两条要同时满足。
  • 关掉扫描软件里的锐化 / 自动曝光 / 去网纹，避免它改写格线与笔迹的灰度关系。
  • 一页一个文件，文件名随意 —— 页序由页脚的编码方块自动识别。
  • 整页方向不对也没关系（比如纸横着放进了扫描仪）：程序会自动试 0 / 90 / 180 / 270 度并转正。

没有扫描仪时也可以用手机拍，但要满足四条：① 从正上方拍、尽量对正；② 让纸占满画面（宽度 70% 以上），否则页脚的小方块会糊在一起、页序读不出来；③ 把纸压平；④ 要认红圈就用扫描 App（如扫描全能王）的「智能高清」档 —— 手机相机直拍与相机自带的「文档矫正」模式实测都会把红圈颜色抹淡（9 个圈只认出 0~1 个）；不圈字的件用相机直拍没问题。

用扫描类 App（如扫描全能王）时选「智能高清」（软件默认档），其它档会识别失败。2026-10-11 逐档实测（同一张纸、9 个红圈）：只有「智能高清」9 个圈全中且页脚与切格全对；「原图 / 灰度」纸底没去掉（纸面偏灰）会让页脚读不出、整格被当成墨迹，「去阴影」会漏掉定位块，其余档能切格但红圈会丢。道理是两条要同时满足：纸底要去干净（纸面灰度要明显亮于笔迹提取阈值，否则整页判读失效）、颜色要保留（红圈识别靠颜色通道差值：红墨水的红通道明显高于绿、蓝通道，转灰度就没了）。

四、上传与更正

给一个文件夹（第 1 步压缩包解压出来的图片与字序.json），程序自己定出每页写了哪些字；写错的字用更正册按顺序重写，配对在同一页的「更正核对」里可以逐行核对与调整（不改就用程序给的那一套）。

  • 建议浏览器：Chrome 或 Edge 86 及以上（Windows 7 上可装到 109）。第 2 步选文件夹用的是系统文件夹对话框，Firefox 与 Safari 没有这个接口 —— 它们仍能用（程序会自动改成普通文件夹选择器），但看不到"像装软件选路径"那种对话框。
  • 指定一个文件夹就行，也不必改文件名顺序：把扫好的图片与第 1 步压缩包里的 `字序.json` 放在同一层，选中那个文件夹即可 —— 一次放几页、隔几天再补几页都行。选完在回执行上点「看文件清单」，能看清这一轮挑了哪些图片与字序文件，不要的图片可以当场去掉（只动这一轮，磁盘上的文件不动）。字序优先按字序文件定（文件把这一批的顺序写死了，最省事也最准）；文件夹里没有字序文件时，程序会认出每页印着的参考字、自己把字序定出来。
  • 识别是串行的（逐页处理、边跑边显示），可以随时中止；中止后已识别的页会保留。
  • 页级结果一页一张卡片：文件名、状态（已识别 / 失败 / 更正册 / 重复页 / 已作废）、一行统计与「看格子」「作废」「重传」三个操作；把鼠标停在卡片上会显示这一页的完整信息（页号是怎么定下来的、本页校验码、方向纠正、四角误差、字序来源、写出统计）。
  • 后来才补扫了几页：识别完之后按钮行里有「补传扫描件」，把那几张一次选进来即可 —— 程序按页号归位：已经有这一页就覆盖它（连字形一起换），是新的一页就追加；补完记得回第 3 步重新生成一次字体。重写完的那一页也走这条路（见下面"重写"那一段）。
  • 只认本程序模板产出的纸：四角定位块找不到、或纸上找不到模板印的参考字，这一页会明确失败并说明原因，不会产生任何字形 —— 随便一张图或别的程序打的纸都进不来。
  • 每页会自己校验一次：模板页脚印着一串编码方块，里面存的是"这一页那些字"的指纹。程序识别完会拿自己认出来的字再算一遍，两边一致才收下 —— 对不上就说明这一页的页号或字序认错了，程序会先拿指纹把页号反推一次，仍对不上就明确失败（那一页重扫即可）。所以你不需要逐格去核对字。
  • 单页失败（找不到四角定位块等）只跳过那一页并在卡片上标红，不影响其它页 —— 照着卡片上的原因重扫那一页、点「重传」再传即可。重传与补传只看"这一页能不能识别"，不再拿纸面的编码拦人：认得出是同一张纸就收下。

写错的字怎么办：更正册按「被圈字的顺序」从第 1 格起、一格一个字重写 —— 这个顺序就是主区页码的先后 + 同一页里格子从左到右、从上到下的先后（写之前请照着纸面右侧的页码把圈字排一排，见"书写"那一段的加粗说明）。写坏的格用红笔圈掉、在后面按顺序补写；留空的格表示这个字保留主区的原字形 —— 所以写坏一格不必整册重写。更正册只保留一份，重传会覆盖旧的。

识别完成后，同一页下半部分的「更正核对」会把「第 k 个被圈字 ↔ 更正册第 m 格」并排列出来，可以改派 / 删除 / 补录；配对默认生效，直接用于生成字体（不需要点确认）—— 逐行核对着看是防"整体错位"的最后一道闸。改过之后想退回程序给的配对，点核对表那一行右侧的「恢复默认」。作废 / 重传 / 补传更正册之后，配对会自动重算（旧的手动调整一并作废）。

五、生成字体与安装

第 3 步一页到底：填名称表、生成字体、下载 zip；装完记得重启 Word / PS。

  • 第 3 步一页到底：先填名称表（族名 / 全名 / 版本 / 设计者 / 版权 / 许可等，都有默认值；改了要重新生成一次），再点「生成字体」；生成完成后同一页出现下载区。
  • 下载 zip，解压得到一个文件夹：字体三件（.ttf / .woff / .woff2）、font.css、使用说明.txt、preview.html（双击就能看样张）。「字体预览」标题行右边是三个动作：查看字形总览、查看网页预览（都在新标签页里打开，看完关掉即可；想存档就在那一页上右键另存 / Ctrl+S）与最右的下载 zip。
  • 不装机也能先看效果：同一页的「字体预览」把刚生成的字体当场注册进页面，输入文字即可实时预览，还能切 24 / 36 / 56 像素三档字号；字体没收录的字会用浅红底标出来并列在下面。
  • 安装：Windows 右键 .ttf → 「为所有用户安装」（或复制到 C:\Windows\Fonts）；macOS 双击 → 「安装字体」。装完请重启 Word / PS —— 它们只在启动时读一次字体列表。
  • 在 Word 里到字体列表选这个族名即可；网页里把 font.css 与字体文件放同一目录，然后 font-family 用它。
  • 没写的字不会进字体：在 Word 里显示成方框、在浏览器与 PS 里回退成系统字体（预览里会被标出来）—— 但已写的字完全不受影响。
  • 写得不理想的字（第 3 步的字形体检）：体检面板默认收起，只显示一行摘要（有几个建议重写、几个已剔除），点开才看清单 —— 四栏做成标签页（建议重写 / 只是留意 / 重写清单 / 已剔除的字），每页 20 条；它只提示、不改字形。判"建议重写"的那批字，你可以加入重写清单（这次先不进字体、以后补上）或剔除（这个字不要了）—— 两者这一次都不进字体，区别是前者会挂在清单上等着你补。重写清单那一栏有「下载重写模板」：按下这些字印一张模板（页号接在现有纸之后、纸面右侧印着它的页码），照着写完，用第 2 步的「补传扫描件」丢进来即可 —— 补传之后，写过的那些字会自动移出重写清单（新写的字形直接顶掉旧的，不必再去手动移出）。
  • 重写页写坏了怎么办：重写模板不需要另配更正册 —— 重新下载一份重写模板、重写一次、再补传一遍即可（同一页号会覆盖上一份，"后写的优先"）。只有主区那些页上的错字才走空白更正册那套流程。
  • 还有一个更省事的路子：第 3 步「字体预览」里没收录的字会列在下面，它后面紧跟「生成补写模板」—— 同样是印一张模板、写完补传回来，与重写模板走同一条路（页号都接在现有纸之后，所以补回来是"追加新页"，不会覆盖已经识别过的那几页）。
  • 想重来：第 2 步「识别」页右上角的「清空结果」把识别结果、字形与体检信息清掉，回到"还没识别"（模板与名称表保留，扫描件文件夹重指一次就能重跑）；要连模板与名称表一起复位、彻底回到刚打开软件的状态，用第 3 步右上角的「清空全部数据」（点它会先弹窗、要求输入「清空」两个字确认）。两个动作都不可撤销。
  • 所以不必一次写完：先写最常用的那批就能用起来 —— 只写「一级常用字 + 基础字符」约 27 页、写「常用 6500 字」约 50 页；之后补写新字、重新生成字体即可，多次识别的字形会合并进同一套字库。

数据只保存在本机浏览器里：刷新、关掉浏览器都不会丢（识别结果与字形落在浏览器的本地存储里），但清理浏览器数据、换电脑或换浏览器就会没有 —— 那时把扫描件文件夹重指一次、重跑一遍识别即可（同样的输入必得同样的结果，全量 61 页约 100 秒）。扫描件原图程序不保存，请自己留一份。

六、常见问题

打印尺寸不对、找不到定位块、字写小了、字体装完 Word 里没有 —— 先看这几条。

  • 打印出来格子不是 1cm：检查是否选了「实际大小 / 100%」、是否误勾了「无边距 / 无边框」；先用自检页量一次。
  • 提示找不到四角定位块：确认纸的四角完整没被裁、纸面平整、打印是实际大小；重扫一次通常就好。
  • 字写小了、成字后偏小：见「二、书写」—— 笔画多的字要写到刚刚触到格子边；本软件已把书写格按 1:1 映射到字身框（不再缩小）。
  • 字体装上后 Word 里找不到：先重启 Word / PS；仍没有就用 `npm run inspect:os2`（或看使用说明.txt）确认字体字段，或重装一次。
  • 刷新页面后：识别结果与字形掩膜都已落盘 —— 重新生成字体不需要重扫；格级大图与更正核对里的缩略图会当场从落盘的字形重画（主区十几页时稍等一下）。
  • 能不能只做一部分字：可以。第 1 步「自定义选字」里按分类或检索挑字 —— 字网格可以按「使用频率」或「笔画序」排列（与模板的「排列方式」是同一处设置），翻页时能一键「全选本页」（一页 340 字），分类树下方还有「全选全部」（全量 8274 字）；出一批写一批，多次识别的字形会合并进同一套字库。
  • 浏览器要求：用较新的 Chrome 或 Edge（90 以上；选文件夹的系统对话框要 86 以上，两者都满足）即可，Win7 上装 Chrome / Edge 109（最后一个支持 Win7 的版本）同样能用；IE 不支持。能力不够时打开页面会有一条中文提示，说明缺哪一项、哪一步会干不了。Firefox / Safari 也能跑，只是第 2 步选文件夹用的是普通文件夹选择器（它们没有系统文件夹对话框的接口）。

七、参考与借鉴

版式与流程思路参考了做字体网（zuoziti.com）的公开模板与教程；代码、字体、字表与全部实现均为自研。

本软件的版式设计与流程思路参考了 做字体网（zuoziti.com） 公开的模板与教程。具体是：

  • 版式几何：A4 横向、每行 17 格 × 1.6cm、书写格 1cm、参考字 14pt、表格居中（实测自其标准模板 V4.0）；
  • 灰色格线 + 灰色参考字：让程序靠灰度把"印上去的参考字"与"手写笔迹"分开；
  • "照着写、不描红"的产品形态；
  • 错字处理：红笔圈出后单独重写（本软件改成"红圈 + 顺序对应 + 界面核对"）；
  • 字形体检（超标 / 偏小 / 杂点分类筛查）与字形总览图（版权登记辅助）；
  • 字体名称表中英双语的写法；
  • 切图前必须水平矫正 → 本软件的方向自动纠正；
  • 文件名排序坑（1、10、2… 需零补齐）→ 本软件按自然序读取。

没有照搬、以及被本软件实测修正的地方（如实说明）：① 字表改用《通用规范汉字表》官方口径（8274 字），不再取用其任何资料；② 教程要求"必须彩色喷墨"—— 实测放宽为黑白喷墨也可用，只有黑白激光暂不承诺；③ 教程的"不要导出 PDF 打印"不适用：本软件直接生成 PDF，不存在 Word 转 PDF 那一步；④ 教程里 FontForge 的"分批导入（每批 ≤3000）"不做：本软件 8274 字一次构建约 30 秒。

除上述版式与思路之外，本软件的代码、字体、字表与全部实现均为自研；做字体网的资料只作为参考文献留在开发仓库之外，不随本软件分发。

第三方组件与许可：内置字体都是 OFL-1.1 —— 霞鹜文楷（模板上的参考字）与悠哉字体 Yozai（「书写示意」的示范字），许可全文随程序包附在 `fonts/OFL.txt` 与 `fonts/OFL-yozai.txt`；生成字体用到的开源库（pdf-lib、pdf.js、fonteditor-core、jszip、esm-potrace-wasm 等）的完整清单与许可写在开发仓库的 `THIRD-PARTY-NOTICES.md` 里。
