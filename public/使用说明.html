SxFontCreator 使用说明

手写字体制作器 · 离线说明

一、打印模板

彩色打印、按实际大小（100%）、不勾无边距；先打最后一页自检页量 1cm 方框。

在第 1 步「选字与出模板」里先决定写哪些字（不选就按全量 6919 字出），再点「生成模板 PDF」。生成范围建议先用「单页试打」确认版式和打印设置。

  • 用彩色喷墨打印机；打印对话框里选「实际大小 / 100%」，不要选「适合页面」——那会把格子缩放掉。
  • 不要勾「无边距」（有些驱动叫「无边框」）：它会把内容放大到铺满整张纸，格子就不是 1cm 了。
  • 不建议用黑白激光打印：它会把灰色格线打成黑色，扫描时混进字形里。
  • 模板文末有一页打印自检页，先打它、用尺子量上面的 1cm 方框与 10cm 标尺，确认是 100% 再打全部。
  • 每页 8 行 × 17 格 = 136 格，书写格是 1cm × 1cm 的实尺寸；页脚那排小方块是页码与批次校验码，别裁掉。

选字清单一旦改动，必须重新生成模板：页脚的批次校验码会跟着变，拿旧模板写的纸在上传识别时会被判为「与所选批次不符」而整批拦下。

二、书写

0.5mm 黑色中性笔，居中书写、别出格：笔画多的字写到刚刚触到格子边，笔画少的字（如日、一、小）居中写小些。

  • 用 0.5mm 黑色中性笔；一笔写成，不描不改。
  • 居中书写、大小匀称、别写出格子。
  • 笔画多的字：写到刚刚触到格子边为宜（撑满格、但不要出格）—— 这样整套字的大小才均一。
  • 笔画少的字（如「日」「一」「小」）：本身就该写小一些，居中写即可；硬撑满格反而难看，成字后大小不匀。
  • 写错的字：用红笔把这一格的参考字圈起来（统一圈参考字，不要圈书写格）—— 第 4 步会按圈到的顺序生成更正册。
  • 纸面别翘边、折叠或受潮：纸张一旦变形（非平面形变），任何透视校正都救不回来。

模板每页顶部印了一行要点，写的时候照着看即可：「A4彩打,不缩放,不勾无边距;0.5mm黑色中性笔,居中书写,别出格,不描不改,写错用红笔圈参考字,防止纸张翘边,折叠,受潮;扫描用照片模式,图像类型彩色,300dpi。」

三、扫描

平板扫描仪、彩色 300dpi、照片模式；纸放正压平，一页一个文件。

  • 建议用平板扫描仪（实测设备 EPSON L4266 一体机，彩色 300dpi 就够，只用到它约四分之一的能力）。
  • 色彩模式选「照片 / 彩色照片」，不要选「文档 / 文字文档」：文档模式会自动去底色、拉高对比度，把灰格线、淡参考字与红圈的颜色信息一起改掉。
  • 关掉扫描软件里的锐化 / 自动曝光 / 去网纹，避免它改写格线与笔迹的灰度关系。
  • 一页一个文件，文件名随意 —— 页序由页脚的编码方块自动识别。
  • 整页方向不对也没关系（比如纸横着放进了扫描仪）：程序会自动试 0 / 90 / 180 / 270 度并转正。

没有扫描仪时也可以用手机拍，但要满足四条：① 打开相机的「文档矫正 / 扫描」模式；② 从正上方拍、尽量对正；③ 让纸占满画面（宽度 70% 以上），否则页脚的小方块会糊在一起、页序读不出来；④ 把纸压平。

用扫描类 App（如扫描全能王）时务必选保留颜色的模式：实测「原图 / 增亮 / 增强锐化 / 智能高清 / 去阴影」都能保留红圈的红色，可以用；「黑白 / 省墨 / 灰度」会把红色压成灰黑，红圈识别随之明显变差。原因：红圈识别靠颜色通道差值（红墨水的红通道明显高于绿、蓝通道），一旦转成灰度，这个信息就没有了。

四、上传与更正

上传前先选批次；写错的字用更正册按顺序重写，配对结果要在第 4 步确认。

  • 上传前先选「这批扫描件属于哪个批次」；改过选字清单的旧批次会被标记为已作废，需要显式勾选才放行。
  • 识别是串行的（逐页处理、边跑边显示），可以随时中止；中止后已识别的页会保留。
  • 页级结果会给出：页号来源、批次校验码是否一致、方向是否被自动纠正、四角误差、写出 / 可疑 / 被圈的格数；失败页整行标红并说明原因。
  • 页脚读不出的页：在结果里手动排定页序，并勾选「确认这批扫描件属于所选批次」（此时批次校验码也一并失效，必须由你确认）。
  • 单页失败（找不到四角定位块等）只跳过那一页并标红，不影响其它页 —— 照着提示重扫那一页再传即可。

写错的字怎么办：更正册按「被圈字的顺序」从第 1 格起、一格一个字重写。写坏的格用红笔圈掉、在后面按顺序补写；留空的格表示这个字保留主区的原字形 —— 所以写坏一格不必整册重写。更正册只保留一份，重传会覆盖旧的。

第 4 步会把「第 k 个被圈字 ↔ 更正册第 m 格」并排列出来，可以改派 / 删除 / 补录；只有点了确认才能进入生成字体 —— 这是防"整体错位"的最后一道闸。配对一变，确认会自动复位。

五、生成字体与安装

第 5 步填名称表并生成字体，第 6 步下载 zip；装完记得重启 Word / PS。

  • 第 5 步可以改字体族名、全名、版本、设计者、版权、许可等字段（都有默认值）；改了之后要重新生成一次。
  • 第 6 步下载 zip，解压得到一个文件夹：字体三件（.ttf / .woff / .woff2）、font.css、使用说明.txt、preview.html（双击就能看样张）。
  • 不装机也能先看效果：第 6 步的「网页字体预览」把刚生成的字体当场注册进页面，输入文字即可实时预览，还能切 24 / 36 / 56 像素三档字号；字体没收录的字会用浅红底标出来并列在下面。
  • 安装：Windows 右键 .ttf → 「为所有用户安装」（或复制到 C:\Windows\Fonts）；macOS 双击 → 「安装字体」。装完请重启 Word / PS —— 它们只在启动时读一次字体列表。
  • 在 Word 里到字体列表选这个族名即可；网页里把 font.css 与字体文件放同一目录，然后 font-family 用它。
  • 没收录的字在 Word 里显示成方框、在 PS 里可能回退到别的字体（预览里会被标出来）—— 想拿到一套完整可用的字体，建议先把常用字补齐（前 2000 字覆盖日常语料约 97%，约 15 页）。

数据只保存在本机浏览器里：复制程序目录、把程序发给别人都不会带走数据。换电脑、重装系统、清理浏览器数据之前，请先用右上角的「项目备份」导出一份项目包。

项目备份（导出 / 导入项目包）：顶栏右上角「项目备份」→「导出项目包」，得到一个 zip，里面是 project.json（名称表 / 批次 / 进度 / 更正记录）、glyphs/（字形掩膜，PNG 无损）与一份说明.txt。

  • 包内不含扫描件原图：识别时原图是"读完即释放"的，从不落盘 —— 原图请自己留一份（纸还在手上，重扫一次也能得到同样的字形）。
  • 导入会整份替换当前项目：选好 zip 后，程序先列出包里有什么（族名 / 选字 / 批次 / 识别页数 / 字形数 / 更正记录），确认之后才真的覆盖；覆盖前程序会把"被替换掉的那一份"另存在浏览器里保底，但它没有界面入口。
  • 导入完成后页面会自动重新加载。识别结果的缩略图与掩膜是内存里的临时产物，重新生成字体时按需重建，不用重新扫描。
  • 第 3 步识别完成、第 5 步生成字体之后，界面上各会提醒一次「建议导出项目包备份」；导出过之后这次会话内不再提醒。

六、常见问题

打印尺寸不对、找不到定位块、字写小了、字体装完 Word 里没有 —— 先看这几条。

  • 打印出来格子不是 1cm：检查是否选了「实际大小 / 100%」、是否误勾了「无边距 / 无边框」；先用自检页量一次。
  • 提示找不到四角定位块：确认纸的四角完整没被裁、纸面平整、打印是实际大小；重扫一次通常就好。
  • 字写小了、成字后偏小：见「二、书写」—— 笔画多的字要写到刚刚触到格子边；本软件已把书写格按 1:1 映射到字身框（不再缩小）。
  • 字体装上后 Word 里找不到：先重启 Word / PS；仍没有就用 `npm run inspect:os2`（或看使用说明.txt）确认字体字段，或重装一次。
  • 刷新页面后缩略图没了：识别结果与字形掩膜都已落盘，重新生成字体不需要重扫；只想看格级大图才需要重新上传识别一次。
  • 能不能只做一部分字：可以。第 1 步「自定义选字」里按分类或检索挑字，出一批写一批，多批次的字形会合并进同一套字库。
  • 浏览器要求：用较新的 Chrome 或 Edge（90 以上）即可，Win7 上装 Chrome / Edge 109（最后一个支持 Win7 的版本）同样能用；IE 不支持。能力不够时打开页面会有一条中文提示，说明缺哪一项、哪一步会干不了。
