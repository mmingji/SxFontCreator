## 来源与核对

- 官方出处：国务院公报 [国发〔2013〕23号](https://www.gov.cn/gongbao/content/2013/content_2481095.htm)；教育部资料页附官方 PDF（`通用规范汉字表.pdf`，扫描件、无文字层，已加入忽略清单）。
- **三个来源逐序号互证、零差异**（2026-10-08）：① 本文件；② Unicode Unihan 数据库的 `kTGH` 字段（8105 条）；③ 维基文库官方转录（<https://zh.wikisource.org/wiki/通用规范汉字表>）。核对方法与实测数据见 `docs/字表标准与收字口径.md`。
- 拼音列仅供查阅（例如将来做首字母检索），**不参与字序** —— 字序一律用序号（笔画序）。
